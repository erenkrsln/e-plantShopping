# e-plantShopping

e-plantShopping is a React-based shopping cart application for an online plant store called Paradise Nursery.

The application allows users to browse different categories of house plants, view plant details, add products to the shopping cart, change quantities, remove items, and view the total cart cost.

## Features

- Landing page for Paradise Nursery
- Product listing with multiple plant categories
- Add plants to the shopping cart
- Increase or decrease product quantities
- Remove products from the cart
- Display total number of cart items
- Calculate the total shopping cart price
- Continue Shopping and Checkout buttons

## Technologies

- React
- JavaScript
- Redux Toolkit
- HTML
- CSS
